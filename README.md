# СЯзык

**СЯзык** — русский компилятор C/C++ на базе Clang/LLVM с русскими ключевыми словами,
русскими препроцессорными директивами и переведёнными сообщениями об ошибках.

## Возможности

- ~80 русских ключевых слов C/C++ (вместо `if` → `если`, `while` → `пока` и т. д.)
- Русские препроцессорные директивы (`#включить` вместо `#include`, `#определить` вместо `#define`)
- ~740 переведённых сообщений об ошибках и предупреждений

## Сборка

Сборка происходит автоматически на GitHub Actions при пуше в репозиторий.
Бинарник компилируется для архитектуры **aarch64** (Android) со статической линковкой.

### Структура репозитория CLang.Ru

/.github/workflows/Build.yml — инструкция сборки на GitHub Actions
/.github/ApplyPatch.sh — скрипт применения патчей (Python) 
/LICENSE — лицензия
